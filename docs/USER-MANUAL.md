# Aurabot 使用手册（给不懂技术的你）

> 大肥鱼的「家」在 DeepSeek Harness（下面简称 DSH）里，QQ 是她的手机。
> 所有设置都在 DSH 左侧栏「自动化任务」下面的 **Aurabot** 里。

## 一、第一次使用（大约 10 分钟）

第一次打开 Aurabot 会自动出现 **设置向导**，跟着走 5 步就行。以后想重新走，可以在「连接」标签点「重新走一遍设置向导」。如果升级前已连上 QQ 且机器人号核对通过，向导会显示「使用现有连接，进入面板」，点它即可保留当前设置并完成向导。

### 1. 你们的 QQ 号
- **机器人 QQ 号**：给大肥鱼用的号，**一定要用小号**。
- **你的 QQ 号（主人）**：操作电脑这些只听主人的。

### 2. 准备 SnowLuma（让机器人号能上线的 QQ 网关）
> 已经有 QQ 机器人服务（NapCat、LLOneBot、Lagrange、Docker 里的 SnowLuma……），或者在 Linux / Docker 上跑 DSH？在这一步选 **「接我已有的 OneBot 机器人」**，填它的正向 WebSocket 地址（和 token，有的话）就行，下面 SnowLuma 的几步都不用做。插件只连接，不启动、不注入任何东西，连上后会先核对登录的是不是机器人号。

SnowLuma 的协议不允许别的程序替你下载安装，所以这一步要你自己来（只做一次）：
1. 点「打开下载页」，下载名字类似 `SnowLuma-v2.x.x-win-x64.zip` 的文件（**不带 lite** 的完整版）。
2. 解压到一个纯英文目录，推荐 `C:\Aurabot\snowluma`。解压后这个目录里应该能直接看到 `index.mjs`。
3. 填好目录后点「检查」，会显示「找到了 SnowLuma」。

### 3. 启动并同意协议
1. 点 **启动 SnowLuma**。它在后台运行，不会弹黑窗口。
2. 控制台密码由插件 **自动生成并保存**，你不用设，也不用记。
3. 面板里会显示 SnowLuma 的用户协议和隐私说明。读完后勾选「我已阅读并同意」，再点 **同意**。

> 如果你之前自己在 SnowLuma 控制台里设过密码，这里会提示「插件登不上」，点 **重置为自动密码** 就好。

### 4. 接入机器人号
1. 电脑上另开一个 QQ，登录机器人号，可以最小化。你的主号 QQ 照常开着，不用管。**QQ 需要 NT 版（9.9 及以上）；老版 QQ 注入不了，先升级 QQ。**
2. 点 **接入机器人号**。Aurabot 只给登录机器人号的那个 QQ 进程接入，**你的主号永远不会被碰**。点「看看有哪些 QQ 进程」可以亲眼确认：主号那一行写着「不会碰」。
3. 等十几秒，看到「连上了：大肥鱼（机器人号）」就成功了。

### 5. 先试运行，再正式上线
1. 推荐选 **先试运行**：她会照常思考，但只把要说的话写进日志，**不会真的发出去**。
2. 用你的主号给机器人号发一句「在吗」，然后去「日志」标签看她本来要回什么。
3. 觉得没问题，就把右上角的 **试运行** 关掉，她就正式上线了。

- **QQ 会话放在哪**：默认在用户目录下的 Aurabot\qq-chats，想放到别的盘就在「连接」页填完整路径（比如 D:\Aurabot\qq-chats）。

## 二、日常怎么用

| 想做的事 | 去哪里 |
|---|---|
| 让她暂时别说话 | 关掉右上角的 **总开关** |
| 只看她想说什么、不真发 | 打开 **试运行** |
| 把她拉进一个群 | 先在 QQ 里拉机器人号进群，再到 **聊天 → 群聊** 输入群号，选择「仅模块」或「允许 AI 聊天」，保存 |
| 允许某个朋友私聊她 | **权限 → 私聊用户**，输入对方 QQ 号，开启「允许私聊」 |
| 改她的性格 | **人格** 标签：直接改文字，保存后下一句起生效 |
| 换一套人格 | **人格** 标签：选中一个，点「设为当前」 |
| 让她在群里话多一点或少一点 | **聊天 → 群聊**：选群调整主动加入和窗口接话；通用规则在「群聊通用设置」 |
| 在私聊里让她帮你操作电脑 | **权限** →「主人私聊的权限」选「完整」（默认就是） |
| 换声音 | **语音** 标签：选音色，点「生成」试听；也可以用「翻唱」页导入的 RVC 音色给语音条变声（说话和唱歌同一个声音） |
| 管理表情包 | **表情包** 标签：可以改名字、删除、上传新的 |
| 让她马上写一篇空间日记 | **空间日记** →「现在写一篇」 |
| 让她现在来找你 | **概览** 或 **主动搭话** →「现在就让她来找我」 |
| 查看 Token 用量与缓存命中率 | **概览 → Tokens 用量**：点开查看每个群和私聊，可切换今天、近 7 天等时段。价格无法可靠确认时不显示金额。 |
| 看她和某个人聊了什么 | DSH 左侧栏的「Aurabot · QQ」工作区，点对应的会话 |
| 插一句话帮她回 | 在那个会话里直接打字，她这一轮的回复也会发到 QQ |

### 人格的人设图与外貌

在 **人格 → 编辑人格 → 人设图与外貌** 设置。每个人格独立保存最多 8 张图片和一段最多 2000 字的外貌描述，原有单图自动作为第一张保留，切换人格后下一轮采用对应外貌。

| 操作 | 保存方式与效果 |
|---|---|
| 添加 / 替换人设图 | 新人格先点「保存人格」；支持 PNG、JPG、GIF、WebP，每张最大 5MB。点「添加人设图」可一次多选；每张卡片的「替换这张」只替换该图。上传立即保存，图片变化后提示重新确认外貌 |
| 外貌解析模型 | 仅用于读取人设图、生成外貌描述，不会更换聊天或生图模型。默认使用「模型」页设置的全局聊天模型，也可单独选择支持看图的模型。所有人格共用此设置；更换后先点页面底部「保存设置」 |
| 从人设图生成描述 | 点击后才将全部已保存的人设图发送给外貌解析模型。结果先填入文本框，可手动修改，确认后点「保存人格」才生效。生成期间手动修改的文字会保留 |
| 手动编辑外貌 | 随「保存人格」一起保存；空文字可清除外貌设定。未保存的外貌会随人格正文保存在本机草稿中 |
| 用于生图参考 | 每张图片独立开关，默认全部开启，修改立即保存。关闭后仍保留图片且参与外貌描述解析，但不会作为生图参考图上传 |
| 图片备注 | 每张最多 120 字，如「工作服」「常服」「Q版形象」；点「保存备注」生效。仅实际传入生图服务的图片会附带对应备注。替换图片保留开关及备注 |
| 删除人设图 | 每张卡片的「删除这张」立即删除该图，其他图片及外貌描述保留；删除整个人格时一并删除全部图片与外貌 |

人设图与左侧的 **面板头像** 分开保存，不会自动修改 QQ 头像。图片仅供视觉解析和生图参考，不直接加入聊天上下文；保存的外貌文字会加入人格提示词。点击「从人设图生成描述」才会把图片发送给外貌解析模型。

让她「画你自己」时，工具使用 `image=self`（也接受 `自己`、`人设图`），默认传入全部已开启人设图，并附上外貌文字和各图备注。支持数量少于已选数量时，按图片顺序取前几张并说明；服务明确只支持单图时，使用已开启的第一张。全部关闭或不支持参考图时仅按文字生成，并提示形象一致性限制。工具结果会报告实际使用张数。鉴权、限流和网络错误不会触发降级重试，主人权限规则保持不变。

指定聊天图片进行编辑时，`image` 传单张，`images` 传多张，顺序对应提示词中的图 1、图 2。两项同时填写时，`image` 排在最前。只使用明确指定的图片，不自动补入其他群友的图片；缺图、图片过期或服务支持的数量不足时会停止并说明原因，不会少传几张或改用纯文字绘制。下表的人设图降级仅适用于 `image=self`。

| 生图接法 | 参考图传递 |
|---|---|
| OpenAI 兼容 | 多图按 `image[]` multipart 上传，最多取人格的 8 张；实际兼容能力取决于服务。明确的单图限制会尝试第一张，不支持参考图时尝试文字生成 |
| 自定义接口 | `{image}` 为单张 base64；`{images}` 为多张 base64 数组。在 POST JSON 参数中将值完整填写为 `{images}`，发送 JSON 数组；GET 或表单中发送 JSON 数组字符串。参数名按服务文档填写 |
| 本地脚本 | `supportsImage=true` 为单图；`supportsImages=true` 为多图，可声明 `maxReferenceImages` 限制张数。详见本地接口说明 |
| Codex / 图生图关闭 | 使用外貌文字生成，不上传参考图 |

### 在 QQ 里直接管她

主人可在私聊或白名单群里使用这些命令；其他私聊用户仅可使用单独授权的命令。总开关关着时命令仍可用。权限管理命令只接受主人私聊。

| 命令 | 作用 |
|---|---|
| `/silent`（`/闭嘴`） | 在这个聊天里先不说话；`/silent 30` 是安静 30 分钟 |
| `/active`（`/说话`） | 解除闭嘴 |
| `/quiet` `/chatty` `/normal` | 这个群里：不插话 / 话多一点 / 恢复默认 |
| `/model`（`/模型`） | 看能用的模型；`/model 2` 或 `/model 名字` 换，`/model 默认` 跟随 DSH |
| `/effort`（`/思考`） | 查看当前聊天所用模型在 DSH 中提供的思考档位。发送 `/effort 2` 或 `/effort 档位名` 切换，仅影响本聊天中的该模型。`/effort 默认` 恢复跟随面板。 |
| `/status`（`/状态`） | 看她现在的状态 |
| `/diary`（`/日记`） | 马上写一篇空间日记 |
| `/remember 内容`（`/记住`） | 让她记住一件事 |
| `/reset`（`/重开`） | 这个聊天重新开始 |
| `/off` `/on` | 关掉 / 打开总开关 |
| `/help` | 看全部命令 |
| `/权限` | 主人私聊管理白名单、功能和命令授权 |

重开聊天用 `/reset` 或 `/重开`，没有 `/clear` 别名。未识别的命令会直接提示未执行；没有权限的命令也不会交给模型假装执行。扩展模块自己的消息指令照常优先处理。

#### 清理某个 QQ 用户的记忆

在「权限 → 私聊用户」或「人物记忆」详情中选择「清理记忆并重开私聊」。确认后会清除该用户的画像、事实、关系和相处经验，归档已有的 DSH 私聊会话。清理前的相关流水及 QQ 历史不再补入机器人上下文，下一条私聊会开新会话。QQ 历史、DSH 旧会话和权限设置仍可查看。若已设置「不再记住」，该设置继续生效；其他情况下，新消息会正常积累记忆。

#### QQ 中管理权限

在 DSH 打开「权限 → 私聊用户」，输入 QQ 号或从好友列表搜索。选中用户即可查看和调整该人的功能与命令授权，开关即时保存。「授予会话自助」会同时开放 `/help` 和 `/reset`。关闭私聊后，其他授权会暂停。

普通私聊用户的功能和命令授权默认关闭，生效时同时检查私聊白名单和对应授权。群白名单控制哪些群可以处理消息；是否由 AI 接话还看群响应模式，个人授权仅在对应私聊生效。主人账号由「主人」设置管理，`/权限` 和单用户授权入口无法修改主人权限，也不能把主人专用命令授权给别人。生图和点歌的「仅主人」总开关关闭时，按该功能的全局设置开放。

主人也可以在 QQ 私聊发送 `/权限` 查看用法。

- `/权限 12345678` 查看这个人的授权。
- `/权限 授权 12345678 私聊 生图 reset` 一次开放私聊、生图和 `/reset`。
- `/权限 撤销 12345678 生图 reset` 一次撤销两项授权。
- `/权限 命令` 查看可授权命令。扩展命令需由模块明确声明可授权。`/model` 只改变该用户的私聊模型。
- `/权限 列表 群` 查看群名单；`/权限 添加 群 群号`、`/权限 移除 群 群号` 管理群白名单。
- `/权限 档位` 查看资料和社交操作的全局档位；`/权限 档位 项目 off|owner|all` 修改。`all` 会对所有符合条件的聊天开放。

### 按群控制接话和记忆

「聊天」分为三块：
- **群聊**：选一个群，调整模式、接话和旁听；点「群聊通用设置」可调整各群共用的规则，单独设置过的项目不受影响。
- **回复方式**：消息合并、回复发送和等待时间。
- **权限与限制**：不回应哪些人、管理指令、跨群查看和文件权限。

改好后点「保存设置」。选择群模式会自动处理白名单，无需到权限页再加一次；添加群号本身不会开放聊天。权限页保留直达入口和默认收起的旧名单编辑。

**想保留 `#表情`，但连 @ 也不让 AI 接话？** 到「聊天 → 群聊」，选择「仅模块」，保存即可。也可以主人私聊发送：

```text
/群设置 修改 123456789 模式 仅模块
```

- **不响应群消息**：移出白名单，群消息不触发模块或 AI。
- **仅模块**：加入白名单，模块照常工作；@、叫名字、引用、戳一戳、主动和窗口接话均不触发 AI。
- **允许 AI 聊天**：加入白名单，按原有规则聊天，模块也可用。指令中写 `模式 允许AI聊天`。

「不响应时仍旁听」只决定不响应群消息时，是否继续记住新文字。「仅模块」和「允许 AI 聊天」原本就按群记忆规则处理，不用另开旁听；关掉旁听也不会停止这两种模式的记忆。

定时推送、模块开关和权限另行设置；有些模块也会使用 AI。已开始的工具任务不会被强行取消。仅模块时，原来的主动和窗口设置保留，恢复 AI 聊天后才生效。`/quiet`、`/normal` 或重新加白不会解除「仅模块」。

**最简单：主人私聊里直接说；只操作一个群时带上群号。**

- 「查询所有群的发言和记忆设置。」——列出机器人实际加入的群；群多时分批显示，会提示是否还有未列出的群。
- 「把群 123456789 设为仅模块，@ 也不要 AI 回复。」
- 「群 123456789 别主动插话，但聊起来可以接话。」
- 「把群 123456789 加入旁听名单。」或「从旁听名单移出。」
- 「看看群 123456789 的发言和记忆设置。」——一次查白名单、被叫到回复、主动/窗口接话、概率、旁听，以及当前受什么限制。
- 「群 123456789 的接话恢复默认。」——恢复该群所有接话设置，不改旁听名单。

结果也能在面板「聊天」页查看。接话开关只在「允许 AI 聊天」时生效；旁听只额外记录非白名单群的新文字，不让机器人回复。旁听整理可能产生费用；移出名单不删旧记忆，也不停止白名单群原有的记录。

**想避免模型理解偏差，就用指令：** 仅主人私聊，输入 `/群设置` 随时看用法。

```text
/群设置 查看 全部
/群设置 查看 123456789
/群设置 修改 123456789 主动 关 窗口 开
/群设置 修改 123456789,987654321 旁听 开
/群设置 修改 全部 主动 关
```

查询按群分段显示白名单、被叫到回复、主动/窗口接话和记忆；暂停等限制会单独说明。想看完整的概率、次数和静默时段，查看单个群。

- 模式可填「不响应群消息、仅模块、允许AI聊天」，支持单群和批量；不要与「白名单」同时填写。
- 可改「主动、窗口、旁听、白名单」，每项后填「开」或「关」；没写的项不动。只关主动，不会移出白名单或关闭窗口。
- 批量或「全部」先列群号和改动，再按回复中的确认指令保存；2 分钟过期，`/群设置 取消` 可放弃。一次最多修改 100 个群。「全部」仅指查询时实际加入的群，不包含后来加入的群。
- `/群设置 恢复 群号` 恢复该群全部接话默认（含概率等），不改响应模式、白名单、旁听或聊天暂停；多个群号也可用逗号分隔。查询群多时按回复翻页。
- 面板「聊天 → 主人私聊：群设置指令」可关闭整套指令，默认开启。它与自然语言管理独立；想关闭自然语言管理，在「权限」页关闭「改白名单」。原有 `/权限`、`/quiet` 不受这个开关影响。
- 试运行或调试时，指令只预览，不保存；预览后相关设置被别处改过，需要重新发起。
- 指令出错时，QQ 只显示简短原因或处理建议，详细报错留在本机。若提示「发送 / 保存未确认」，先查看目标聊天或设置，不要连续重复执行。

QQ 指令中的「窗口」对应面板的「聊起来后继续回应」，现有指令用法不变。

**手动设置：** 在「允许 AI 聊天」模式下，不想主动凑热闹，就关闭「没人叫时主动插话」、打开「聊起来后继续回应」。机器人最近 3 分钟说过话时，可以继续接相关话题；并非每条都回。两项都关闭，也不禁止被 @ 等明确叫到时回复。模块的定时推送另行设置。

**在目标群里用命令：** `/quiet` 关闭两项接话，`/chatty` 打开两项并提高插话概率，`/normal` 恢复默认。`/silent` 是暂停整个聊天，连 @ 也不回；用 `/active` 恢复。它们与面板共用设置。

- 插话概率为 0 时不会主动加入。私聊要求开启会自动恢复非零全局概率；全局也为 0 时用 15%，机器人会告知结果。
- 试运行、调试时，私聊修改只预览、不保存。关闭「权限」中的「改白名单」或「好友申请与白名单」模块后，不能再通过自然语言管理这些设置。
- 面板提示“设置已在别处修改”时，本次没有保存。先记下要保留的改动，再点「读取最新设置」重新调整。

## 三、她会做的事

- **聊天**：短句、口语，想说的多会拆成几条，每条之间像真人一样停顿一下。
- **一轮说几段怎么发（可选）**：面板「聊天」页的「每段都发」有三档——「只发最后一段」（默认）、「自动（推荐）」（纯对话轮她分几段就发几条；这一轮调过工具、在干活，就并成一条发）、「每段都发」。不开分条时，同一轮里分开成段的正文会按顺序拼成一条，不会再被最后一段整段覆盖；但和工具调用写在同一段里的过程话仍会被当成过程话丢掉。分条时另有一个「近似去重阈值」（默认 0.45）：同一份结果被复述两遍只发一条，后一段顶掉前一段；最高只能设到 1，而「去掉标点空白后完全相同」的两段仍会被判重复，想完全不去重只能不开分条。

- **群聊**：被 @、有人回复她、或者提到「大肥鱼」「肥鱼」时会回，群聊安全刹车和闭嘴设置仍然生效。一个人 @ 或引用她时，她的第一条回复会引用那条消息并真正 @ 对方；多人同时找她时不猜要 @ 谁。其他时候偶尔插一句，也可能选择不说话。
- **看引用**：别人引用一条消息时，她会去查被引用的内容（谁说的、正文、几张图/表情），私聊和群聊都能看到；引用的是她自己以前说的话时会标成「你」。引用里的图片和表情包也会作为附件给她看（最多 2 张）。查不到时她会知道「这条引用没读到」，可以如实说没看到，不会装作看见了。

- **主人私聊问群里的情况（本地默认开，可在面板关掉）**：面板「聊天 → 主人私聊：群聊摘要」打开后，你在私聊里问「群里刚才在聊什么」，她会把最近 24 小时白名单群的聊天流水当成自己看到的见闻接着说，不会当成你发给她的消息；不常驻上下文、不写进记忆。可限定只取哪些群、每个群给几条（最多 30 条）。只在主人私聊且这句话提到群相关时触发。
- **在群里 @ 人**：她 @ 谁，对方会真的收到 QQ 的 @ 提醒。她按群名片和 QQ 昵称找人；对不上、或者群里有两个同名的，她就不 @，只把名字当普通文字发出去。注意：你手机上给好友设的**备注**她看不到。比如你备注叫「小明」、他在群里叫「Luna」，你说「去 @小明」她是找不到的，告诉她群名片或 QQ 号就行，对不上时她也会跟你说没 @ 到。
- **替你去别的群 / 私聊说话**：在和她的私聊里说「去 XX 群说一声……」「跟 XX 私聊说……」，她会过去说（对方要在白名单里）。下次那个群再有人找她时，她记得自己刚才在那里说过什么，能接上话。
- **看图片文件**：主人把 JPG 或 PNG 作为文件发进群，再 @ 她问「这张图里有什么」，也可以在私聊里问。只在询问时读取当前聊天的文件，单个不超过 2 MB；需要当前模型支持看图。
- **发文件**：在和她的私聊里说「把 XX 文件发给我」就行，她也能按你说的发给白名单里的人或群。她只能发 QQ 工作区（她平时写文件的地方）和你在「聊天」页「发文件」里额外加的目录中的文件；单个文件默认最大 50 MB；每次发了什么会写进日志。这个功能在「聊天」页可以关掉。
- **危险命令确认（默认开）**：面板「安全防护」页可以关。她在私聊里要执行删除根目录、格式化、关机、下载后直接执行这类终端命令之前，会先发 QQ 私聊问你；回复「确认」才执行，回复「取消」或 60 秒没回就拦下，她也会把实际要执行的命令原文如实告诉你。群聊和其他人的会话没有本地终端工具，不会碰到这个开关。
- **看图**：支持视觉的模型可以看别人发来的图片和表情包；转发给她的聊天记录（合并转发）她也能展开看。面板「模型」页的「视觉能力」可以手动声明聊天模型收不收图，也可以在「识图模型」里单独挑一个会看图的模型：选好以后，收到的图片先交给它看，它写一段画面描述再交给聊天模型，聊天模型本身就不用能看图了（适合用便宜的快模型聊天）；识图时的思考强度在「识图思考强度」里单独设（低 / 高 / 最高），和聊天用的档位互不影响。她画完图后，支持视觉的聊天模型也能收到图片附件；大图需要本机 ffmpeg 缩图，缩图或附件服务不可用时她会如实说没看到。面板里「让她画完自己看一眼」关掉、或「视觉能力」选「不支持」且没配识图模型时，画完只回一句「画好了」。
- **主人专用生图**：群里主人真正 @ 她或引用回复她提出画图请求时，同批普通群友消息不会误拦生图；如果多个人同时 @ / 引用回复提出请求，请分开发送。主人仅参与闲聊不会让群友获得生图权限，授权也不会沿用到下一轮。这一例外只用于生图，不改变改资料、发文件等操作的权限。
- **GIF 动图（可选）**：接口支持 GIF 时，在「生图」打开「允许按需生成 GIF」。说“画一只挥手的小鲸鱼，做成循环 GIF”或“把这张图里的猫变成眨眼动图”即可；普通画图默认仍是静态。动图默认小尺寸、约 1.6 秒，可能更慢、更费额度。目前只支持内置 OpenAI 格式接法；失败不自动换静态图或切备用服务。原动图发到 QQ 并存入图库，聊天模型只看第一帧预览，不能据此判断完整动作。
- **生图构图**：可以让她画方图、竖图、横图或宽幅，也能在「生图」页设置默认构图。工具本次指定优先于默认值；没有指定且默认是「让她选择」时，沿用原来的图片尺寸。四档尺寸分别为 1024×1024、1024×1536、1536×1024、1536×864。自定义接口使用 `{size}` / `{width}` / `{height}` 才会跟随构图，写死的参数仍按接口配置发送；服务不支持尺寸时会如实报错。
- **Codex 订阅生图（实验性）**：在「生图」页选择该接法并登录 ChatGPT，再保存配置。它使用非公开图片端点，可用性、支持的模型和额度由账号、工作区及服务端决定；不是公开 API 兼容性承诺。令牌单独保存在插件数据目录 `codex-auth.json`，不会放进配置或返回面板。登录使用本机 1455 回调；端口被占用时可粘贴完整回调地址，取消 / 超时 / 卸载会关闭本次登录。退出会删除插件保存的登录信息。该接法将所选构图作为提示词引导，实际尺寸由服务端选择，不保证严格比例。
- **用自己画的图**：画完会告诉她一个「画作编号」（#1 是最新那张）。想拿它换 QQ 头像，说「用画作 #1 换头像」；想收进表情库，说「把画作 #1 存成表情」。编号只在本聊天有效，重启后会重新算（画作文件一直都在）。
- **存刚收到的表情 / 图片**：主人说「存一下刚才的表情」时，她会从本聊天最近收到的图片中取图。每个聊天保留最近 6 张的短期引用，重启后可以恢复；有效期从收到时起算 30 分钟，重启不会延长。图片来源本身已经失效时，需要重新发图。
- **查看自己的 QQ 资料**：主人在 QQ 私聊里提到她的昵称、个性签名或头像时，她可以主动查询当前资料。例如问「你现在叫什么」「签名是什么」「喜欢现在的头像吗」。讨论头像画面时，如果把头像交给支持看图的聊天模型，会作为附件提供；聊天模型看不了图时会用「识图模型」写一段描述回来（也配不出能看图的模型时如实说明）。查询仅限主人私聊，与修改资料的权限分别判断；查询本身不会发图或修改资料。
- **发送自己的当前头像**：主人在 QQ 私聊中说「把现在头像发出来」「发你的头像给我」时，她会用 `qq_send_avatar` 直接发送当前头像图片，无需先识图。试运行或调试模式不真实发送；网关未确认时不会报告成功。关闭「改资料」模块后，查询和发送头像工具都会撤销。
- **换自己的头像**：私聊里说「用刚才那张图换头像」，或者画完图说「用画作 #1 换头像」都行。图太大会自动缩到 640 以内再交给网关；缩不了或网关不接受时会如实说明，不会假装换好了。
- **换 B 站头像**：同样说「用画作 #1 换 B 站头像」或「用刚才那张图换 B 站头像」就行。B 站上限 2MB，超过会自动缩小；没登录 B 站或 Cookie 过期时会如实说明。
- **戳一戳**：戳她会有反应，偶尔还会戳回来。
- **语音**：心情到了会发语音条；别人发的语音她会先转成文字再听。想让她说话也用「翻唱」里导入的音色，在面板「语音」页开「语音条变声（用翻唱音色）」选一个音色（翻唱环境要先装好；变声失败会用 TTS 原声，不影响发送）。
- **让她去另一个群发语音**：直接说“去某某群用语音说一下……”。跨聊天工具支持直接指定语音，模型不必手写语音标签；旧的正确标签仍可用。标签写坏会先提示模型改正，不会先把半条消息发出去。语音合成失败时仍可能改发文字，回执会说明实际发送的类型；等待补发不算已经送达。
- **云端语音识别（可选）**：面板「语音识别」页里选「硅基流动」或「OpenAI」，填 Key；地址和模型留空会用预置值。默认顺序是本地脚本 → QQ 自带转文字 → 云端识别 → DSH 识别；想优先走云端，把「先用谁」切成「先云端识别」（实测硅基 SenseVoice 一次约 14 秒，QQ 通常 1~2 秒）。点「测试云端识别」会先念一句再听回来。
- **表情包**：会自己收藏群里看到的表情包（普通照片不收），并给每张起个名字。表情的名字和标签能在面板「表情包」页直接改（鼠标移到表情上，点名字或标签，改完点别处就保存）。QQ 表情商店里的商城表情会按原样发，动画由 QQ 自己播。在「表情包」页把总开关关掉，她就一张都不发了。
- **限制回复配图（可选）**：在「表达 → 表情包」打开「回复里的表情也受概率限制」，再调概率。每段回复只抽一次，不叠加心情；没抽中只去掉表情，不改正文，因此可能“说要发图却没发”。更在意聊天连贯时可以关闭，无需还原代码。`#表情` 制作和 QQ 小黄脸不受影响。默认关闭。
- **纯表情或提到图片时保留（实验性）**：先打开上面的概率限制，再开启此项。只发表情、没有正文时直接保留；带正文时，命中“图、表情、一张、这张、看看、给你整”等任一关键词，就保留已有表情，0% 也保留；有正文且没命中才按概率抽。也识别照片、贴纸、发个、换个、收下以及 image、sticker、meme 等词。不会因为命中而额外配图，不检查表情标签里的名字。这是宽松文字匹配，例如“地图”也会放行；隐含承诺仍可能漏掉。默认关闭。
- **怎么偷表情（三种模式）**：面板「表情包 → 怎么偷」里选。「全都偷」是默认，看到就收；「她挑」只把表情记下来、给她一句轻提示，她喜欢才凭编号收；「只听主人的」只在主人私聊、或这一轮只有主人说话时才提示她收，有别人在场时她不能自己收，要主人发话。两种新模式下，表情会暂存 30 分钟（重启不丢），她可以用 `qq_collect_sticker` 按编号收，也能收自己刚画的图。
- **QQ 小黄脸**：她会在文字里夹 QQ 自带的系统表情（/捂脸 /斜眼笑 /吃瓜 这种），和文字在同一条消息里；别人发来的小黄脸她也认得是哪个。不想要就在「表情包」页关掉「夹 QQ 小黄脸」。
- **空间日记**：每天在 QQ 空间发两条说说，写当天的事。谁能看和 QQ 空间自己的选项一致：所有人、好友、部分好友可见、部分好友不可见、仅自己；选了两个「部分好友」要填名单，名单为空时她不会发（也不会退回公开）。「日记配图」开着时，每篇会从今天她画的图 / 今天收的表情包里挑一张配上去，没有合适的就只发文字。聊天里让她发说说时，只能收窄成「仅自己」，不能扩大你在面板里定的范围。
- **空间互动**：有人评论她的说说会回（接着回她也会接着聊）；逛好友动态时偶尔点赞、评一句（在「空间日记」页打开）。
- **刷 B 站**：在「B站」页打开后，她会定时刷几个视频，看到好玩的私聊分享给你，也会自己发评论、回别人；你在 QQ 里发 B 站链接她也能看。
- **B 站看画面和截图**：在「B站」页打开「让她看画面」（默认关闭），安装 ffmpeg 并使用支持图片的模型。每个视频抽 2～12 帧，画面描述会和字幕、简介、热评一起交给她阅读；缺少 ffmpeg、模型明确不支持图片、取流或视觉调用失败时继续读文字。抽到的图片存在本机截图库，默认保留最近 300 张，可以在面板预览、删除、调整上限。QQ 聊天里说「有哪些截图」「发张刚才那个视频的截图」，她会按标题或画面备注挑选，发到当前会话。定时刷完默认有 35% 概率向主人私聊发一张，调成 0 就不自动发；试运行不会实际发送，也不会报告已经发送。
- **人声分离模型下不动**：安装会自动换国内镜像、断点续传；还不行就照面板「翻唱」页给的地址用浏览器下好，拖进「音色模型」框。
- **本地接口**：想用自己的 GPT-SoVITS、SD WebUI、自己训练的音色？在「本地接口」页生成模板，照注释改或者「复制给 DSH 的话」让 DSH 改，打开开关就行。
- **翻唱**：用导入的音色唱歌，完成后发到点歌的聊天。制作时间取决于歌曲长度和电脑性能，CPU 可能需要数分钟以上；不保证两三分钟完成。主人可在群里或私聊用 `/sing 歌名` 点歌。
  - 不指定片段：按面板「语音条最长 / 截哪一段」处理，短歌唱整首，长歌截一段；“副歌附近”只是全曲约 30% 的位置。
  - 唱前 30 秒：`/sing 红日 李克勤 +12 时长=30`。
  - 从第 60 秒唱 30 秒：`/sing 红日 李克勤 +12 开始=60 时长=30`。秒数填整数，不能超过已保存的最长时长；遇到歌尾就唱到结尾。
  - 也可自然语言说「翻唱《红日》，从第 60 秒开始唱 30 秒」，或在翻唱面板「试唱」填写开始秒数和时长。仅影响这次点歌。只说歌名会从搜索结果挑可用版本；想听某位歌手就带上歌手名，指定录音版本可在面板搜索后选曲。
  - 群聊自然语言点歌若混入其他人的请求，可能被权限保护拒绝；主人直接发 `/sing` 更确定，不必放开点歌权限。
- **主动搭话**：只在和你的私聊里。你一阵子没理她，她会主动来找你；她问了你一句你很久没回，偶尔会轻轻追一句。群里不会这样。
- **心情**：面板「人设 → 心情」页。上面是整体的心情数值（0～100，被夸会涨、被凶会掉，过一阵子慢慢回到「平常是多少」那个基线），下面是「此刻的情绪」——每种心情各一条进度条，会随时间淡去（和上面用同一个「多久回到平常」）。「心情项」可以展开自己改：增删情绪、改名字和图标、调它偏正还是偏负（-1～+1）、强还是弱（0～1）；删掉的项她就不会再出现这种心情，改名字只影响显示和措辞、不动已经记下的数据。想要额外的心情就在那里「添加一项」，想退回默认点「恢复出厂十项」。心情好时ta话多、更爱发表情和语音、回得快、群里更爱插话；心情差时话少、回得慢、少发表情。
- **她的小闹钟**：在「主动搭话」页打开后，她可以在和你的私聊里自己设 `yyyy-mm-dd HH:MM` 的一次性提醒；到点会触发主动搭话系统提醒，让她按当时说好的内容来找你。面板可设最多 1～10 条，并可查看/手动关闭；触发失败默认保留 15 分钟、每 5 分钟重试，也可以关掉重试。
- **记忆**：每天整理两次（默认 4 点和 16 点），把聊天提炼成长期记忆、相处经验，还会慢慢学会你们的说话方式。这些关于人和群的内容都在面板「人物记忆」页，能看也能改；开关和调参在「心情与记忆」页。这里可以把「自动记忆容量」从默认的 3000 条调高，最多 100000 条：聊天提炼、经历和日记按各自配额分配；手动记忆和分档事实不受此限制。提高容量不会关闭已有的过期和压缩规则。
- **精排 Reranker（可选）**：在「心情与记忆 → 重排候选」里打开。它会对已经找出来的候选逐条重新打分，把真正相关的排前面；默认用硅基免费的 `BAAI/bge-reranker-v2-m3`，地址/Key 留空就复用 embedding 的服务。超时（默认 2 秒）或失败会保留原来的关键词 + 向量顺序，不影响回复；只处理已经过群聊/人物权限过滤的候选。
- **语义检索（可选）**：面板「心情与记忆 → 向量检索」打开后，记忆会额外发给 embedding 服务换成本机向量；这样她说「那个毛茸茸的小东西」时也能想起「橘猫年糕」。硅基填 `https://api.siliconflow.cn/v1` + `BAAI/bge-m3`；方舟填 `https://ark.cn-beijing.volces.com/api/v3` + 开通的 `doubao-embedding-*`；本地 Ollama 填 `http://127.0.0.1:11434/v1` + `bge-m3`，不用 Key。详细配置、参数和排错见 [EMBEDDING.md](EMBEDDING.md)。注意：它提高的是「按意思找旧记忆」，不是把更多轮聊天塞进上下文。

### 想让她多会点什么？（「模块」分组）

更多功能可以在面板「模块市场」安装，每个模块的说明在模块库里。

她的每项本事都是一个**模块**，在「已安装」页里：

- **不想要某项本事**：把那一行的开关关掉。比如不想让她刷 B 站，关掉「B站」，她就不会刷，也不会答应别人去看视频。
- **想改某项本事**：点那一行的「复制一份来改」，再点「复制给 DSH 的话」，粘给 DSH，写上你想怎么改（比如「空间日记写短一点，多用颜文字」）。DSH 改完保存，几秒内就生效。
- **想让她学会新本事**：在「新建一个模块」里起个英文名（比如 weather），点「新建」，把自动复制好的话粘给 DSH，写上你想要什么（比如「群里有人问天气，就去查一下告诉他」）。
- **先试试再上线**：「已安装」页最下面的「模拟测试」能假装发一句话、调一个工具，看模块会怎么反应，发出去的东西只显示在面板上，不会真发到 QQ。
- **改坏了**：那一行会显示红色的报错；你改的内置模块坏了会先自动用回原来的。实在不行就打开「安全模式」，你写的东西全部不加载，她恢复原样。
- 你写的东西放在 `%USERPROFILE%\.dsh\plugins-data\aurabot\modules\`，**升级插件不会动它们**。

## 四、出问题先看这里

> 换电脑：面板「系统 → 备份」点「立即备份」，把生成的文件拷到新电脑。新电脑装好 DSH 和 Aurabot 后，把文件拖到同一页（首次设置的向导里也有入口），重启 DSH 后会自动换上设置和数据、重新下载市场模块、放回 QQ 会话。备份里有账号凭证，别发给别人；DSH 自己的设置、QQ 网关登录和抖音、小黑盒的浏览器登录要重新弄。

> 装不上、报错了：先看面板「日志」里的报错和插件版本号；也可以扫 [README](../README.md#联系我们) 里的二维码加 QQ 交流群问，或在 GitHub 仓库开 issue（带上日志和版本号会快很多）。

| 现象 | 怎么办 |
|---|---|
| 她完全不回消息 | 1. 右上角总开关开了吗？试运行关了吗？ 2. 去「连接」看「QQ 网关」是不是「已连上」。 3. 对方在白名单里吗？ 4. 看「日志」标签有没有红字。 |
| 「QQ 网关」一直连不上 | 机器人号的 QQ 开着吗？QQ 重启过的话，去「连接」点「接入机器人号」。 |
| 「接入机器人号」说找不到 | 确认机器人号的 QQ 已经登录完成，等十几秒再点一次。 |
| 重启 DSH 后有一阵发不出消息 | 一般不用管。网关暂时连不上时会自动等几秒重试；上一个 SnowLuma 还没退干净时，会先等它释放端口，或者直接接着用它。刚连上那一会儿收到的消息也会补上。日志里看到「网关暂时连不上，…后重试」是正常的；一直重试失败再看上面那行。 |
| 她说 @ 了人，对方却没收到提醒 | 她只认群名片和 QQ 昵称，认不出你手机上给好友设的备注。告诉她对方的群名片或 QQ 号再让她 @ 一次。 |
| 群里她不说话 | 在「聊天 → 群聊」检查模式：只有「允许 AI 聊天」才会由 AI 接话；再检查总开关和暂停。 |
| 某个功能的标签页不见了 | 去「已安装」页看看对应的模块是不是关了。 |
| 翻唱安装报「HTTPS 证书校验没通过」 | 网络里的代理、加速器或安全软件在中间换了证书。先关掉它们再点安装；插件会对能核对校验值的文件自动换一种连接重下。还不行就按下面「手动放置预训练文件」把文件放进去。 |
| 翻唱说「读不了某个模型文件」 | 多半是杀毒软件（360、火绒、Defender）拦住了。把翻唱目录（比如 `E:\Aurabot\rvc`）加进杀毒软件的信任区；还不行就删掉提示里那个文件，在「翻唱」页重新下载。 |
| 装了自己写的模块后她不对劲 | 「已安装」页打开「安全模式」，你写的模块全部不加载。恢复正常就说明是那个模块的问题，看它那一行的报错。 |
| 语音发不出来 | 会自动改发文字。想要更好听的声音，在「语音」标签点「安装 edge-tts」。 |
| 回复很慢 | 「模型」标签里把思考强度选「低」；也取决于模型服务本身的速度。 |
| DSH 启动时报「Web authentication failed」 | 这是 DSH 自己的问题（本机登录 Cookie 攒太多）。关掉 DSH，删除 `%APPDATA%\@deepseek-ai\dsh-desktop\Network\Cookies` 里 127.0.0.1 的旧 Cookie 后重开即可；或者把报告发给我处理。 |
| 桌宠明明在跑，面板却一直显示「离线」 | 先看 DSH 桌面端的「浏览器访问」开关开没开：它关着时，桌宠客户端发出的所有请求（包括心跳）都会被 DSH 当成普通浏览器请求拦下（一律 403），在线状态就永远登记不上——桌宠程序本身没坏。把开关打开，桌宠下一次心跳（半分钟内）就会自动上线。 |

所有日志都在：`%USERPROFILE%\.dsh\plugins-data\aurabot\logs\`
所有数据（设置、人格、表情、日记、记忆）都在：`%USERPROFILE%\.dsh\plugins-data\aurabot\`

## 五、关于账号安全

- 机器人一定要用小号。用 SnowLuma 这类非官方工具有被腾讯限制或封号的风险，主号千万别拿来当机器人。
- SnowLuma 只给机器人号注入，你的主号进程永远不会被碰。
- 群聊里的大肥鱼没有任何操作电脑的能力；只有和你私聊时，在「完整」权限下才可以。

## 六、桌宠：把「大肥鱼」请到桌面上（小白跟做版）

1.2.0 起桌宠是社区模块：先在面板「模块市场」点安装，「桌宠」页才会出现。

桌宠是一个会待在你屏幕角落的小「大肥鱼」：她主动搭话会冒气泡，你也可以点她聊天。
不用懂任何技术，全程点按钮就行。

### 第 1 步：打开桌宠页面

打开机器人面板 → 顶部点「表达」→ 点「桌宠」。

### 第 2 步：点三个按钮（按顺序）

1. 点 **「下载 / 生成客户端」**——这一步把桌宠程序生成到数据目录，几秒就好。
2. 点 **「安装 Electron」**——桌宠的"引擎"，约 100 多 MB，走国内镜像，**1~3 分钟**，
   期间按钮可能没反应，等提示出现再动。
   - 这一步**不需要你装过 Node、npm 或任何编程环境**：有条件就用 npm 装，
     没有就自动直接下载官方压缩包解开，全自动判断。
3. 点 **「启动桌宠」**——桌面上出现大肥鱼就成功了！
4. （可选）想让她开机就在，把 DSH 设置成开机自启，再开桌宠页里的对应开关。

> 三个按钮都灰着或点了没反应？重启一下 DSH 再试。

### 第 3 步：平时怎么用

- **拖拽**：按住她可以甩到屏幕任意位置，会自己稳住。
- **聊天**：左键点她。
- **退出**：任务栏右下角托盘里有她的图标，右键退出；或回面板点「停止桌宠」。
- 她的心跳（在线状态）在面板「桌宠」页能看到；「主动搭话走桌宠」开关决定她搭话是冒气泡还是发 QQ。

### 「安装 Electron」失败怎么办（手动安装，进阶可选）

自动安装一般不会失败；npm 那条路失败时插件会**自动改用 zip 直装**，不用再点第二次。
如果反复失败（断网、杀软死拦），可以先试试把面板「桌宠」页的「Electron 镜像」换成别的地址；
还不行就手动来：

1. 用浏览器打开这个地址（整行复制）：
   `https://npmmirror.com/mirrors/electron/45.1.0/electron-v45.1.0-win32-x64.zip`
   （如果你的电脑是 ARM 芯片，把 `x64` 换成 `arm64`。）
2. 下载得到一个 zip 文件，**右键 → 全部解压**，解压到任意位置。
3. 打开文件夹：按 `Win + R`，输入
   `%USERPROFILE%\.dsh\plugins-data\aurabot\modules-data\pet\app` 回车。
4. 在里面进入 `node_modules` 文件夹（没有就新建一个，名字原样），把解压出来的文件夹
   改名为 `electron`，整个拖进去。
5. 回面板点「启动桌宠」。

> 前提：第 2 步的「下载 / 生成客户端」至少点过一次（`app` 文件夹才存在）。


### 群里不回应某个人

到「聊天 → 权限与限制 → 不回应的人」，添加对方 QQ 号，再选择「仅指定群」并填群号，或明确选择「所有群」。最后点「保存设置」。指定群留空不生效；所有群包括以后加入的群。

这会拦住此人在所选群新发的消息、@、回复、模块指令和戳一戳，不影响私聊或主人。拦截的消息不进入聊天和记忆处理；原有记录、已开始的回复、别人引用或转述的内容不清除。总开关可暂时停用名单；移出某人可解除这条规则。

以前安装过同类自用模块时，先按原名单填写并保存，再停用旧模块，避免两套名单同时拦截。按专属头衔过滤仍单独保留，解除某人的 QQ 号规则不会关闭头衔过滤。

### 固定当前人设，保留记忆

如果切换人格后仍学着旧群聊互怼、使用旧口头禅，在「心情 → ta自己的说话方式」关闭「使用学来的语气与相处建议」，再点「保存设置」。这是全局开关，对所有群和私聊生效；下一轮回复起应用，不需要重开会话。对应配置为 `memory.adaptStyle=false`。

关闭后，不再自动注入学来的说话方式、相处建议及人物档案中的语气/应对字段；学习和存档继续，事实、关系、群印象与记忆召回仍保留。重新打开即恢复注入，旧配置默认开启。

只想重开当前对话时，由主人在目标聊天发送 `/reset` 或 `/重开`。旧 DSH 会话归档，长期记忆不删除；`/clear` 不是内置命令。启用 `chat.seedHistory` 时，新会话仍会补读近期 QQ 记录，且长期记忆会继续召回。若不希望补读，先关闭该设置。

### 用 Fish Audio 发语音

打开「语音 → 扩展服务 → Fish Audio」，点「获取密钥」，填入 API Key；音色 ID 可以留空。要开始使用，再到「发语音」选 Fish Audio，试听后保存。只编辑服务不会切换当前声音。已配置 `FISH_API_KEY` 的用户不用重复填写；在这里填写的 Key 优先，移除并保存后恢复使用 DSH 凭据。面板不回显已保存的密钥。

### 同一语音服务有多个账号

在「语音 → 扩展服务」选中服务，展开「多账号设置」，点「添加账号」填写密钥，保存即可。只用一个账号不必改设置。默认均衡使用；想先用主账号的额度，可将这个服务改为「优先主账号」。各账号使用同一个音色，应都有权使用它。Breeze 的登录、签到仍使用原账号。

在 Fish Audio 设置中点「查询已保存账号」，可分别查看 API 美元余额和套餐点数。免费语音不扣 API 余额；套餐点数不代表还可以合成多少字。

某个账号被限流时会暂时跳过它，按服务返回的时间恢复；服务整体限流时会一起等待。超时或无法确认是否已合成时，不会换一串密钥重复提交同一句。自定义 HTTP 服务可在请求头用 `{apiKey}`（例如 `Authorization: Bearer {apiKey}`），密钥只发往填写时的 HTTPS 站点。

### HTTP 语音失败时的声音

`voice.http.fallback` 可选 `windows`（旧配置默认）、`edge` 或 `text`。`edge` 使用已安装的 Edge TTS 和当前 `voice.voice` 音色；Edge 也失败时交给聊天层改发文字，不继续降成 Windows 语音。`text` 直接将 HTTP 错误交给聊天层，不调用其他合成引擎。

### 不给文字回复自动配表情包

在「表情包」关闭「自动补一张表情包」并保存。这样模型只回复文字时，程序不会再随机补图；模型写出的表情标签仍由「回复里的表情也受概率限制」和概率值控制。明确索要表情时的单独发送、表情收藏和制作不变。这个开关不控制 QQ 小表情或 emoji。旧配置默认开启，保持原有行为。
