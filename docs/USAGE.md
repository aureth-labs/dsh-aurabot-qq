# 查看用量

打开 **概览 → Tokens 用量**，可查看每个群和私聊的输入、输出、合计及缓存命中率。可切换今天、昨天、近 7 天、近 30 天，或全部已记录数据（最多 90 天）。点「刷新」读取最新结果。

费用默认显示**人民币**。在用量明细的「显示币种」可切换为美元等货币，面板会记住选择。展开明细或点「刷新」会按需更新欧洲央行参考汇率；离线时沿用已知汇率，日期见「统计口径与价目」。这只改变显示，不改 Token 记录或自定义费率。

数字默认用 **K（千）、M（百万）、B（十亿）** 简写，例如 `474.78M`。鼠标停在数字上可看完整值；手机也可点「显示精确数字」，再点「使用简写」即可切回。显示方式不会改变统计值。

- **命中率**：输入中有多少 Token 读自缓存。按 Token 数汇总，不平均每轮的百分比。
- **后台用量**：未归入具体聊天的记忆等任务，已包含在总量中。展开「记忆用量」可看更新人物卡、提炼事实、生成向量等任务。旧记录没有标签的，仍留在原分类。
- **费用**：官方参考费用按原厂标准 API 公开价折合美元，中转也按同价；它不是实际扣款。内置价目覆盖 MiniMax M3 / M3.1 Flash、GLM 5.3 系列、DeepSeek V4 Flash / Pro 和 Gemini 3.8 Flash；不按相似名称套价。未定价调用只显示次数，不计作免费。搜索、生图等独立 API 的账单不在这里。
- **记录范围**：只统计服务实际返回的用量。开启统计前未记录的后台调用、服务没有返回的用量，无法补算。重置聊天不会删除已有的用量数字。

## 已有自定义价目表的用户

旧版按模型名猜官方价格，可能不适合中转渠道；现在需要精确的渠道与模型对应关系。不再使用模糊匹配或默认模型价格。没有可靠费率时，保持不配置即可，Token 统计不受影响。

`config.usage.pricing.models` 中，键使用 `渠道ID::完整模型ID`，同时填写 `provider`。`in`、`cached`、`cacheWrite`、`out` 分别是新输入、缓存读取、缓存写入、输出的每百万 Token 价格；币种放在 `config.usage.pricing.currency`。重启插件后生效。可用 `from`（带时区的日期时间）限制适用起点。缺少本次用到的费率，就不显示该次调用的价格；有未定价调用时只显示已定价小计和缺价次数。渠道估算和官方参考费用不相加。

仅适用于已确认的固定费率。不适用于阶梯价、订阅折扣或额外费用；不确定时不要配置。金额始终是参考，以渠道账单为准。
