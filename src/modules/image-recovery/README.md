# 输入被拒后继续聊天

上游明确拒绝输入时，本轮仍显示失败；后续正常消息可以继续使用原会话，无需清空全部聊天。

- 图片专用拒绝：沿用原有行为，让历史图片退出后续请求，保留文字。
- `SensitiveContentDetected`：仅在本轮尚无回复、工具动作或流式输出时，让本轮输入退出后续上下文。原始记录和附件仍保留，不自动重试被拒内容。
- 群聊缓冲及已启用的对话召回也排除对应批次，按消息身份处理，保留之后到达的新消息。

通过宿主的 `surfaceOp: replace` 更新有效上下文，不删除日志，不解析聊天正文来猜测触发词。已产生回复或工具动作的轮次不自动撤回；普通网络错误、额度限制和其他插件会话不受影响。

如果触发内容来自更早的成功对话或系统配置，撤出本轮输入可能仍无法恢复，需要单独检查来源。
